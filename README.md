### 🧠 데이터 분석 사고

**Q1. 데이터를 보고 "무엇을 알고 싶은지(질문)"를 3개 이상 정의할 수 있는가?**
> **A.** [REPORT.md §2 분석 질문](REPORT.md) 에 4개의 분석 질문을 명시하고, 각 질문이 "그래프로 직접 확인 가능한 것" vs "추가 해석이 필요한 것"으로 구분되어 있습니다.
> - Q1: 누적 수익률·분기별 추세 (그래프 직접 확인)
> - Q2: 급등락 이벤트 연결 (추가 해석 필요)
> - Q3: 분기별·월별 수익률 패턴 (그래프 + 해석)
> - Q4: STL 구조적 패턴 확인 (보너스, 추가 해석)

**Q2. 결측치/이상치가 무엇이며, 어떤 기준으로 처리했는지 설명할 수 있는가?**
> **A.** [REPORT.md §3-1 데이터 전처리](REPORT.md) 에 명시되어 있습니다.
> - **결측치**: 거래 공휴일은 행 자체가 없는 구조 → 별도 처리 0건
> - **이상치**: +29.95%(2026-07-31)는 실제 AI 랠리 이벤트이므로 제거 없이 보존 → "제거 시 실제 정보 손실"이라는 근거 포함

**Q3. 그래프에서 확인한 "사실(관찰)"과 "해석(가설)"을 구분해 설명할 수 있는가?**
> **A.** [REPORT.md §5 인사이트](REPORT.md) 의 4개 인사이트가 모두 **관찰(Fact)** = 수치 기반 사실 / **원인(Why)** = 가설·해석 / **행동(Action)** = 후속 제안의 3단 구조로 분리되어 있습니다.

### 📈 시계열 데이터 이해

**Q4. 시계열의 트렌드/계절성/노이즈 개념을 설명할 수 있는가?**
> **A.** [REPORT.md §4-4 STL 분해](REPORT.md) 에서 3가지 컴포넌트를 실제 그래프로 제시했습니다.
> - **트렌드(Trend)**: 주가 상승의 90% 이상을 설명하는 AI·HBM 수요의 장기 구조적 상승 흐름
> - **계절성(Seasonal)**: 연말 특수·분기 결산 효과 등 반복 패턴 → 진폭이 매우 작아 주가에서 계절성 효과는 미미함
> - **잔차(Residual)**: 2026 Q3에 큰 스파이크 → 실적 공시·수주 이벤트에 의한 일회성 충격

**Q5. 이동평균, 변화율 등 기본 시계열 분석 기법을 왜/어떻게 적용했는지 설명할 수 있는가?**
> **A.** [REPORT.md §4-2 이동평균](REPORT.md) 에 선택 근거를 명시했습니다.
> - **20일 이동평균**: 약 1개월(단기 수급·모멘텀)의 노이즈를 제거하고 단기 추세 파악
> - **60일 이동평균**: 1개 분기(실적 발표 주기)의 중기 방향성 리스무스 파악
> - 두 선의 교차 시점(골든크로스/데드크로스)으로 트렌드 전환 시점을 시각적으로 확인

## 🎁 보너스 과제 수행 현황

### ✅ 보너스 ① — 시계열 심화: STL(추세·계절성·잔차 시계열 분해) (수행 완료)

> **요구사항**: 추세/계절성을 분리해 해석하고, 시각화 1개 이상 포함

| 항목 | 내용 |
|------|------|
| 적용 기법 | STL(Seasonal and Trend decomposition using Loess: 국소 회귀 기반 시계열 분해), `period=20` (약 1개월 거래일) |
| 시각화 | [04\_decomposition.png](images/04_decomposition.png) — 원본·추세·계절성·잔차 4분할 |
| 해석 | [REPORT.md §4-4 + 인사이트 4](REPORT.md) — "상승의 90% 이상이 장기 추세, 계절성 효과는 미미, 잔차 스파이크는 공시 이벤트" |

> 💡 **STL을 선택한 이유**: 일반 분해(classical decomposition)는 끝부분 트렌드를 추정할 수 없지만, STL은 전체 구간을 정교하게 분리할 수 있어 최근 데이터(2026 Q3)의 급락 구간도 잔차 분석이 가능합니다.
